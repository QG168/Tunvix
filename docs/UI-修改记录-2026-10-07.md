# UI 修改记录

- 桌面应用图标与关于页采用用户提供的 `Tunvix 品牌字标.png` 原图，保持比例。
- 频道、收藏、最近的背景和点击波纹统一裁剪为 18dp 圆角，避免矩形波纹露出尖角。
- 首页左上角 Tunvix 文字移除点击与长按，保持原有字标样式。
- `:app:assembleLiveDebug` 构建成功。设备测试按用户要求交由用户进行。
- APK：`artifacts/Tunvix-0.1.0.apk`，已同步至手机 Download 同名文件，需手动覆盖安装。

## 输入与全局手势栏修复

- 通用 Field 改为标准 OutlinedTextField，名称、订阅/播放链接、分组名称统一处理完整输入区域的点击和系统输入连接。
- 导航栏从固定白色 SystemBarStyle.light 改为透明 auto 样式；取消单独导航栏占位色块，由页面底部背景延伸至系统手势栏。
- IME 与导航栏 inset 在外层统一消费，键盘出现时固定操作按钮一起上移，避免重复预留底部高度。
- 底部面板与确认/分组弹窗同步透明导航栏配置。
- 编译通过。按用户要求未进行真机操作，输入法唤起及小米实际显示效果待用户验收。
- 官方依据：https://developer.android.com/develop/ui/compose/system/setup-e2e 与 https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2043 。
