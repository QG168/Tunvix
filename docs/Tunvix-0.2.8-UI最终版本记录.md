直播源订阅、本地文件导入和自建频道；频道分组、搜索、收藏和最近观看；视频预览、台标和毫秒耗时标记；普通及全屏播放、遥控换台和音量控制；系统画中画、息屏听音及系统媒体控制；深浅色切换；MP2 音频兼容；XMLTV EPG 订阅管理、节目浏览和频道匹配。
