# 输入法兼容与播放亮屏调整

日期：2026-10-07。仅修改项目代码，未打包新 APK，也未安装或操作手机。

## 第三方输入法

用户反馈：添加订阅时微信输入法无法展开，系统搜狗输入法正常。当前没有微信输入法真机调试证据，因此不认定具体根因或已经通过真机验收。

通用表单 `Field` 使用 `AndroidView` 嵌入原生 `EditText`，由 Android 提供 `EditorInfo` 和 `InputConnection`，保留现有圆角、背景、字号和焦点边框。添加订阅、手动频道及其他使用通用表单的页面同步生效。

获得焦点和再次点击输入框时显式请求键盘；再次点击可重新展开已收起的键盘。文本修改回传 Compose 状态，值相同不重复 `setText`，避免重置中文组合输入、光标与选区。设备测试脚本改为 Espresso 操作原生输入框。

后续由用户检查微信输入法：首次点入、切换字段、中文候选上屏、粘贴长链接、收起键盘后再次点击、编辑现有内容。

## 播放期间保持亮屏

仅当前台处于播放页面、播放状态为 `PLAYING` 且没有进入频道索引覆盖页时，为 Activity 窗口设置 `FLAG_KEEP_SCREEN_ON`，竖屏和全屏均适用。

暂停、退出播放界面、进入后台或播放未处于播放状态时清除此标记；`onStop` 和界面销毁额外清理。系统按照原有息屏时间工作，无需修改系统设置或申请唤醒锁权限。

实现参考：[Android 保持屏幕开启](https://developer.android.com/develop/background-work/background-tasks/awake/screen-on)。
