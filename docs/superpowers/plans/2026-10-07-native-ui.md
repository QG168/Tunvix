# Tunvix 原生 UI 还原实施计划

> 实施方式：用户已指定当前对话负责 UI，其他对话负责后端；由当前对话直接执行。

**目标：** 将根目录 HTML 设计稿还原成可安装、可交互的原生安卓 UI，预留稳定后端接口。
**架构：** app 负责 Compose 页面、导航、交互；core:contract 定义快照和能力接口；demo 和 live 使用独立装配，演示资产不进入 live。
**技术：** Kotlin、Compose、AGP 9.1.1、Gradle 9.3.1、minSdk 29。
**依据：** docs/Tunvix-PRD.md、Tunvix 完整界面设计稿.html。

## 约束与验证重点

- 保留 HTML 的颜色、间距、圆角和矢量图标；不使用模拟系统栏。
- 频道图 16:9 裁切，播放内容等比完整显示；字体放大、窄屏和软键盘不得遮挡操作。
- 多源同名、首尾切台、删除隔离、主动暂停、快速切台为行为验证重点。
- 本地 HTML 浏览器预览被策略阻止：目前以源码数值为视觉基准，不能宣称完成 HTML 渲染逐像素对比。
