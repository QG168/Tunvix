# Tunvix 正式版联调实施记录

依据：PRD、并行开发任务、BC-修复验收。用户已授权当前对话完成剩余接入与打包。

## 计划

- [ ] 1. live 依赖并装配 ABC；暴露加载/读取错误，关闭 catalog 与 playback。
- [ ] 2. 前端截图请求取消、实际保存/历史/错误状态、来源刷新后重新播放。
- [ ] 3. 本地/订阅导入与播放链路测试，回归 ABC/UI 单测与 lint。
- [ ] 4. 小米 14 安装、UI 截图与交互检查；可用时 Android 10 模拟器验收。
- [ ] 5. 输出可安装 APK、验证记录和明确已知限制。

## 决策与进展

- Ruling：继续在用户指定共享目录完成装配，不迁移 worktree；ABC/UI 均未提交，移动会丢失共享交付上下文。
- HTTP 任意源需要应用全局明文访问配置；此前自动审批拒绝过未授权配置，用户已明确回复“允许，支持 HTTP 和 HTTPS”，应用内配置已完成。
- demo 和 live 独立装配，演示频道和图片不得进入 live。
- 初始化失败必须展示错误并禁止空状态保存；ready 表示初始化已结束。
- 主播放开始/页面退出/后台切换要取消可见截图队列；平台阻塞抓帧的限制必须如实记录。

## 当前交付记录

真实 ABC 装配、资源关闭、截图请求取消与刷新后更新播放地址已实现。已输出 `artifacts/Tunvix-0.1.0.apk`，用户手动安装并确认可正常使用和播放。输入框与全局手势栏方案及验证边界见 `docs/Tunvix-第一阶段完整实施方案.md`。Android 10 仪器测试未全部通过，原计划的完整设备验收不标记完成。后续真机测试依用户要求交由用户进行。
