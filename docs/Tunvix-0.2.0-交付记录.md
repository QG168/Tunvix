## 实现内容

1. 首页精简：移除源选择卡片与右上角源管理按钮；顶部左侧 Tunvix 品牌字样下以小字显示当前源名（不可点击，无源显示"未选择直播源"），右侧搜索与刷新并排等尺寸；当前源无频道时刷新置灰不可操作；顶部直接接分组与双列卡片。
2. 底栏第四项"管理"（Glyph.MANAGE），选中/未选中配色复用底栏主题；管理为一级页，无返回箭头，保留底栏。
3. 管理一级页：直播源区预览按目录顺序前 3 个源，选中源不在其中时额外显示、去重；单选标记为蓝紫色勾选，点卡片主体即切换当前源并留在管理页；刷新/编辑/删除独立响应；超过 3 个源提供"查看全部直播源"；无源时显示简洁添加卡片。
4. 应用设置内嵌管理页（顺序：移动网络播放提醒、按键震动反馈、显示首帧耗时、截图存储、清空观看记录、关于 Tunvix）；删除独立设置页与源管理右上角设置入口；截图清理文案说明 Wi-Fi/移动网络均可补图。
5. 页面返回：添加、全部直播源、编辑、关于等二级页隐藏底栏，返回所属实际入口（历史栈）；导入成功进入频道首页。
6. 首帧耗时：UserSettings.firstFrameEnabled（默认关闭、持久保存）；Channel.firstFrame 携带 SUCCESS（毫秒）/TIMEOUT/FAILED 与测量时间；抓帧内部用单调时钟测量（发起媒体请求到第一张可解码画面，不含排队与 JPEG 压缩）；纯检测跳过图片替换；手动刷新同时更新截图与测量，失败保留旧截图并记录超时/失败；结果在播放地址或请求头变化后失效；清理截图不清除测量；检测与截图共享 3 并发名额与 8 秒总超时；关闭开关只取消纯检测任务；检测中状态通过 detectingIds 展示"…"。
7. 标签：半透明深色底、小圆角，仅改文字颜色；1000/3000 ms 原始毫秒值分档（绿/黄/红），超时/失败红色状态文字，未检测/检测中灰色；失败不显示为 0。

## 真机验收项目（用户负责）

1. 底栏四项（频道｜收藏｜最近｜管理）与管理线框图标显示、选中配色。
2. 首页顶部精简布局、源名小字、内容整体上移、无源时刷新不可操作。
3. 管理页源单选切换（含 >3 个源时当前源额外展示）、操作按钮不误触切换、失败提示。
4. 各二级页返回路径与导入成功后进入频道首页。
