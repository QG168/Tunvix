## 界面和原生连接

正式 live 使用 HtmlApp；demo 保留旧演示代码，不作为新 UI 的产品入口。index.html 保留设计 CSS/SVG，views.js 保留页面模板，app.js 接真实状态与操作。native.css 只处理视频合成、横屏适配、已确认的耗时标记及必要状态。

WebViewAssetLoader 从 appassets.androidplatform.net 本地加载界面、台标及截图。WebMessageListener 只接受该来源的主文档消息。阻止其他网页导航/资源、iframe、远程脚本及网页直接网络请求；输入和来源数据转义后显示。播放地址、文件选择、网络请求和存储操作均由原生模块处理。

视频由既有单个 Media3 播放器输出到 TextureView，位于透明 WebView 下方；网页背景通过 SVG alpha 遮罩为视频区域留孔，HTML 控制层保持原设计。视频位置由网页矩形及实际 WebView 尺寸换算，处理圆角、滚动、画面比例、全屏和系统小窗。保留播放帧截图回填，截图不包含网页控件。

小窗隐藏网页，仅展示同一原生视频；进入节目单、匹配和听音页面不停止当前会话。通知打开应用回到实际播放或听音页面。关闭小窗后回到正常首页状态。

| 设计页面/操作 | 原生或真实数据来源 |
| --- | --- |

| 来源刷新 | 在线/文件重新解析；手动来源刷新已有频道预览 |
| 在线/本地解析、结果、确认导入 | SourceImporter + commitImport，复用重复订阅与错误提示 |

| EPG 浏览、匹配、订阅管理 | EpgRepository 缓存/真实节目，来源覆盖/日期/更新时间均来自实际数据 |
| EPG 添加、修改、优先、删除 | 原有订阅接口；内置只读，删除自定义源前确认 |
