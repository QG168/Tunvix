# 内置电视台台标

内置 171 个固定电视频道台标（PNG 合计约 4.47 MiB），包括央视数字主频道、5+、4K/8K、央视专题频道、CGTN、中国教育电视台、全国常见卫视、贵州一至七频道以及部分常见地方台。平台专区、网络轮播和临时赛事不进入内置匹配表。

图片来源为 [vircloud/TVLogo](https://github.com/vircloud/TVLogo)，固定到提交 `bcb7075771a1dc8ef217f77383edb40e2bf2e762`。图片、来源说明及每张图片的 SHA-256 位于 `app/src/main/assets/channel_logos/`。全部素材为上游原始 300×180 PNG，不在运行时下载、转换或更新。

上游 README 仅声明素材来源于公开网络，没有明确的图片再分发许可证。`NOTICE.txt` 和 `SOURCES.tsv` 记录来源，不代表取得台标权利人的公开分发许可。计划公开发布 APK 时，图片分发条件仍需确认。

## 匹配与加载

- 显示优先级：有效预览图 → 内置台标 → 直播源台标 → 通用占位图。
- 根据频道名称匹配，名称不明确时使用已导入的 `tvg-id`（`externalId`）；只接受明确列出的名称与别名，不用包含关系猜测。
- 兼容大小写、常见分隔符、尾部清晰度标记，以及部分频道末尾的备用线路编号。不会把 CCTV-5、CCTV-5+、CCTV-4、CCTV-4K 等合并。
- “新闻综合”“公共频道”等跨地区同名频道不设置全局别名；如缺少明确的频道 ID，继续使用直播源台标。
- 内置图片直接通过 Android assets 读取，复用现有解码和内存缓存。匹配成功且资源有效时不请求直播源台标 URL；已有订阅和手动添加频道无需迁移。
- 台标仍使用预览框约三分之一面积及覆盖整个预览框的背景遮罩；真实预览图仍铺满框。
