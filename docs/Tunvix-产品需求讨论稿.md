# Tunvix 产品需求讨论稿

更新日期：2026-10-07

状态：讨论中。本文记录已确认的需求和待确认事项，不代表完整的实施方案。

## 1. 产品定位与兼容目标

- 名称：Tunvix。
- 用途：播放用户自行导入的电视直播源，不内置直播源。
- 第一阶段主要供用户自己安装 APK 使用。
- 以竖屏使用为主，小米 14 为优先适配和验收设备，同时自适应其他屏幕尺寸。
- 最低支持 Android 10（API 29）；小米设备重点验证澎湃 OS 1 及以上。Android 版本与澎湃 OS 版本分别验证。
- 顶部状态栏、底部系统手势条与页面背景自然融合；文字和操作控件避开摄像头、系统栏和手势区域。实际效果以小米 14 真机验证为准。

## 2. 已确定的界面与视觉方向

### 频道首页

- 参考用户提供的 APTV 截图布局，一行两个频道。
- 每个频道使用长方形直播画面截图，配频道名称。
- 截图采用缓存和按需获取，避免同时加载大量直播流。
- 没有截图或获取失败时显示占位内容，频道仍可进入播放。
- 支持频道分组、搜索和手动切换直播源。
- 卡片截图比例建议为 16:9，细节待视觉设计确认。

### 静态截图策略（已确认）

- 首页使用静态直播截图，按需获取并缓存，不持续播放动态预览。
- 新导入频道进入可见区域后逐个获取截图；已有缓存优先显示缓存。
- 观看视频时暂停其他频道的截图获取，优先保障当前播放。
- 看过的频道使用观看过程中取得的新截图更新缓存。
- 截图获取失败时显示台标或频道名称占位，不阻止进入播放。
- 缓存有效期、容量及后台截图任务的超时在实施方案中确定。

### 网络与流量策略（已确认）

- Wi-Fi 下自动为可见频道按需获取截图。
- 移动网络下优先显示缓存或占位内容，暂停额外的频道截图获取；正在观看的频道仍可使用播放画面更新截图。
- 允许移动网络播放直播，首次使用时提示一次，用户确认后记住选择。
- 首次移动网络提示被取消时不开始播放，也不记为已确认；后续再次尝试时仍可提示。

### 首页导航与添加入口（已确认）

- 顶部第一行：简洁的 Tunvix 文字标识，右侧搜索和源管理按钮。
- 顶部第二行：当前直播源下拉切换和当前订阅源的手动刷新入口。
- 频道页内容区：横向分组栏和双列频道卡片。
- 底部三个入口：频道、收藏、最近；使用统一的图标和文字，选中项使用蓝紫强调色及轻量背景标识，底部背景延伸到系统手势条区域。
- 收藏和最近汇总所有直播源，卡片显示所属源；进入播放后按频道所属源和分组切台。
- 添加直播源不占用独立底栏入口。源管理页提供醒目的“＋添加直播源”，当前源下拉列表末尾也提供快捷入口。
- 无频道时在内容区显示添加直播源主按钮。
- 添加入口提供订阅链接、本地文件和手动添加频道；手动频道统一进入“自建频道”。

### 播放页

- 上方观看视频，下方提供频道列表和遥控器两个面板。
- 下方面板支持左右滑动切换，也提供可点击的“频道 / 遥控器”标签。
- 点击下方频道列表可直接切台。
- 日常保持竖屏，通过按钮手动进入横屏全屏；退出全屏恢复竖屏及之前选择的下方面板。
- 横竖屏切换和下方面板切换应保持当前频道播放，不重新加载直播。
- 视频默认保留完整画面比例，不为了竖屏裁切节目画面。

### 遥控器

- 提供上一台、下一台和音量增减。
- 上一台、下一台按当前频道分组的列表顺序切换，首尾循环。
- 搜索结果不改变遥控器切台顺序；只有一个频道时保持该频道。
- 音量控制手机媒体音量，与手机侧面音量键保持同步。
- 按钮应适合单手操作。

### 视觉风格

- 已取消此前的复古银色拟物方案，当前方向为年轻、清爽、轻盈的现代影音界面。
- 用户已选择“清爽活力”：灰白背景、深色文字、蓝紫强调色，频道画面丰富、界面轻快。
- 频道卡片以大幅画面、适度圆角和简洁频道名称为主，保持双列布局。
- 顶部使用简洁文字标识、轻量直播源选择及统一线性图标；分组选中状态使用强调色或浅色底。
- 播放区域保持黑色，下方操作区延续清爽现代风格；遥控器保留原功能，改用大尺寸圆角控件。
- 不使用拉丝金属、铭牌、实体设备纹理、厚重立体阴影、复古指示灯或复古画面滤镜。
- 精确色值、字体、圆角、间距及动效参数待视觉设计细化；触觉反馈保留已确认的设置开关。

## 3. 直播源与本地数据

### 导入与管理

- 支持订阅链接、本地文件和手动添加频道。
- 导入格式覆盖 M3U/M3U8 频道列表、TXT 频道列表，以及 APTV 使用的兼容订阅列表。
- 手动添加填写频道名称和直接播放链接。
- 手动频道统一存入独立的“自建频道”直播源，可维护名称、链接和分组，不被订阅更新覆盖。
- 支持多个直播源，每个源独立保留频道和分组，由用户手动切换。
- 订阅链接是频道列表地址；手动频道链接是单个频道的直接播放地址。
- 不能仅按 .m3u8 后缀区分频道列表与 HLS 视频清单，需要检查内容。

### 导入流程（已确认）

- 订阅链接：填写源名称和链接，解析后展示频道数和分组数，由用户确认导入。
- 本地文件：选择文件后自动识别格式，源名称默认使用文件名，允许修改。
- 手动频道：填写频道名称、播放链接，可选分组；未选择分组时归入“未分组”，保存到“自建频道”。
- 部分内容无效时导入有效频道并展示跳过条数；全部无法识别时说明原因，不创建空源。
- 重复订阅链接提示已有源，并提供刷新已有源的选项，避免重复添加。
- 重复链接的识别规则、支持的 TXT 变体与编码在实施方案中确定。

### 更新方式

- 订阅源手动刷新，打开 App 时先使用本地保存的列表。
- 刷新操作只更新当前订阅源。
- 更新失败保留原列表；成功后保留能够匹配到的频道收藏和观看记录。
- 本地文件通过重新导入更新，自建频道通过编辑维护。
- 频道截图缓存更新与订阅列表刷新分别处理。

### 收藏与最近观看

- 首版包含收藏和最近观看。
- 记录关联所属直播源，区分不同源中的同名频道。
- 收藏入口已确认；历史条数及订阅更新后的频道匹配规则待确认。

### 频道操作（已确认）

- 长按频道卡片打开操作菜单，所有频道支持收藏或取消收藏。
- 自建频道额外支持编辑名称、播放链接、分组及删除。
- 订阅和文件导入频道首版通过刷新订阅或重新导入维护，不提供单频道编辑和删除。
- 最近观看页额外支持移除该条记录。
- 播放页顶部提供收藏按钮。
- 删除自建频道或整个直播源前要求确认；取消收藏和移除观看记录直接生效。

### 删除直播源（已确认）

- 删除确认框明确说明：删除该源的频道、截图缓存及关联的收藏和最近观看记录。
- 其他直播源的数据保持不变。
- 删除当前源后切换到另一个可用源；没有剩余频道时显示添加入口。
- “自建频道”保留为固定入口，不删除该源本身，其中的频道可以逐条删除。

## 4. 播放生命周期与首版边界

- 返回频道首页：停止播放并释放播放资源。
- 切到其他 App 或锁屏：暂停，停止拉取直播数据。
- 回到仍打开的播放页：恢复当前频道，回到直播位置。
- 首版暂不包含节目单、回看、画中画、首页小播放器和持续后台播放。
- 不因参考截图或订阅携带相关字段而自动扩大首版功能。

### 播放失败处理（已确认方向）

- 加载时显示简洁的加载动效和“正在连接”，允许继续切台或返回。
- 暂时断流自动重试，连续失败后停止重试并提供“重试”和“下一台”按钮。
- 不自动跳过失败频道。
- 地址可能过期时提供刷新所属订阅的入口，刷新失败保留原列表；本地源和自建频道不提供订阅刷新。
- 重试次数、连接超时和具体错误判定在实施方案中确定。

## 5. 首版设置（已确认）

- 设置入口位于源管理页右上角，不新增首页或底栏入口。
- 截图缓存：显示占用空间，支持清理。
- 移动网络播放提醒：支持重新开启。
- 按键震动反馈：提供开关。
- 最近观看：支持清空记录。
- 关于 Tunvix：显示版本号。
- 第一阶段固定使用清爽活力主题，不提供主题切换。

## 7. 技术与环境建议（环境已准备，产品工程尚未建立）

- 当前技术方向：原生 Android，Kotlin + Jetpack Compose + Media3/ExoPlayer。
- 使用 Android 边到边布局和窗口安全区域机制处理系统栏。
- 最低版本 `minSdk = 29`。实际产品工程的编译 SDK、目标 SDK、Gradle Wrapper 和依赖版本仍需在建工程时确定并固定。
- Tunvix 目录尚无 Android 产品工程；环境验证代码和 APK 均保存在独立临时目录。
- 第一阶段暂不需要服务器、远程数据库服务或 NDK。
