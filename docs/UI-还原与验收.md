# Tunvix UI 还原与验收

日期：2026-10-07

## 本次范围

- 原生 Compose 实现，不套 WebView，不把整页作为图片。
- 依据用户 HTML 的颜色、布局尺寸、原始 SVG 路径和 8 张内嵌画面还原。
- 首页、搜索、收藏、最近、播放频道面板、遥控器、横屏、源管理、添加、编辑、导入结果、设置、关于、菜单和错误状态。
- 提供稳定的 SourceImporter、CatalogRepository、PlaybackController 契约和三份并行后端任务。
- demo 使用内存适配器；live 没有演示频道或图片，等待其他对话的模块接入。

## 演示与真实能力的区别

- demo 的画面预览不是视频直播；原图轻微变暗仅用于匹配示意画面。真实视频在控件隐藏时不覆盖暗色渐变。
- demo 导入返回明确标记的演示结果，不访问提交的订阅地址。
- 编辑、删除、收藏、历史和设置在内存中交互，重启可恢复初始演示数据；持久化由 catalog 模块实现。
- 音量操作连接实际手机媒体音量；侧面按键变动会更新显示。
- 系统文件选择器是真的；解析、刷新和截图提取等待后端。
- APK 初版使用 Debug 签名，未作为正式分发版本。
