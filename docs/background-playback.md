# 原生小窗与听音

- 播放器右上角提供小窗、听音按钮，触摸区域 48dp；全屏也提供入口。
- 小窗使用 Android PiP，画面中只显示视频；播放控制、拖动、展开、关闭由系统提供。
- 管理页“返回桌面自动小窗”默认关闭，持久化为 settings 末尾新字段；旧目录缺少字段时为关闭。
- 画中画禁用时提示并跳转系统画中画设置，入口不可用时回退到应用详情。
- 听音仅保留本次播放状态，切台维持听音；明确提供“退出听音”，退出后恢复视频。返回桌面或锁屏继续音频，不进入自动小窗。
- 听音禁用视频轨道，不进行媒体转码；混合音视频流的网络流量取决于源的封装方式。
- MediaSessionService 与界面共享同一个播放器，由服务持有，系统暂停、继续、停止进入同一播放状态机。后台恢复先建立前台媒体服务再申请音频焦点；保留耳机断开、音频焦点丢失时暂停行为。
- 系统停止或划掉最近任务会停止流、清除听音状态、撤下通知并结束服务；服务不自动重启。再次打开为普通视频模式。
- 系统媒体面板按钮位置由厂商控制；提供标准播放暂停和自定义停止指令。

本次按照用户要求只进行源码和 API 检查，未运行测试、实际播放或模拟器验证，未编译或打包。版本号暂保留 0.2.1，打包待用户明确通知。
