## 我为什么做这个播放器

Tunvix 是我自己做的一款 Android 电视直播播放器。平时看电视，我更在意几件小事：频道能方便找到，切台顺手，节目单随时能看；有时只想听新闻，退到后台、锁上屏幕也能接着听。

所以我把频道预览、分组、收藏、节目单、遥控器、小窗和听音放到了一起。界面和操作也是围绕这些日常使用一点点调整的，小米 14 是目前优先适配的机型，同时兼顾其他 Android 手机的屏幕尺寸。

目前版本是 **0.4**，支持 **Android 10 及以上**。安装后添加自己的直播源，就可以开始使用。

## 下载和开始使用

到 [Releases](https://github.com/QG168/Tunvix/releases/latest) 下载 APK，在手机上打开安装。

第一次使用，可以这样操作：

1. 进入「设置 → 直播源管理」，添加在线订阅、本地频道文件，或者手动添加频道。
2. 在线订阅填写名称和地址；本地文件支持 `.m3u`、`.m3u8`、`.txt`。解析后确认导入。
3. 回到首页，选择来源和频道分组，点击频道开始播放。
4. 常看的频道可以收藏，下次从「收藏」或「最近」直接打开。

日常升级下载新版 APK，直接覆盖安装即可沿用原来的直播源、收藏、观看记录和设置。

## 看电视时能做什么

### 频道首页

首页按直播源和分组展示频道，每个频道都有名称、台标和预览区域。预览图会在浏览时获取并缓存，右下角以毫秒显示频道耗时，可以在设置里分别控制耗时显示和预览检测。

常见的央视、卫视和部分地方台台标已经放进安装包，包括贵州一频道到七频道。频道还可以使用直播源提供的台标。首页支持搜索频道，顶部刷新按钮和下拉刷新都能更新预览。

选中的分组和浏览位置会保留。从某个分组进入播放页，下方频道列表也会跟着这个分组走，方便继续在同一组里换台。

### 同名频道和多线路

「合并同名频道」默认开启，同一直播源、同一分组里的同名频道会合并展示。像 `CCTV1` 和 `CCTV-1` 这样的名称也会一并识别。

有多条线路时，会根据已获取的线路状态和耗时选择优先线路。播放页有单独的「线路」按钮，可以手动换一条继续看；合并开关也可以在设置中调整。

### 播放页和全屏

竖屏视频区域固定为 **16:9**，视频按原始比例适应。横屏后可以从「画面」菜单选择：

| 模式 | 显示方式 |
| --- | --- |
| 适应 | 完整显示视频，按比例保留黑边 |
| 填充 | 等比铺满画面，超出的部分裁切 |
| 拉伸 | 将视频铺满整个播放区域 |

横屏换台会保留本次选择，退出横屏后回到「适应」。横屏右上角也可以直接进入小窗、听音，或者切回竖屏。

播放页下方可以在 **频道列表、节目单、遥控器** 之间滑动切换。喜欢进来就换台，或者先看节目单，都可以在设置里选好默认打开的面板。

### 遥控器

遥控器里有亮度条、音量条，以及上一台、下一台按钮。亮度和音量支持连续拖动，调节结果与系统同步。

首次调节系统亮度时，应用会引导打开对应的系统设置权限，之后就可以在播放页直接调节。

### 观影柔光

「观影柔光」默认开启。竖屏正常播放时，连续 5 秒没有操作，视频以外的界面会在 2 秒内慢慢变暗，让注意力留在画面上。

点击、滑动或拖动时，界面会慢慢恢复，第一次点击也会照常执行对应操作。这个功能可以在「设置 → 播放体验」中随时关闭。

## 小窗和后台听音

### 小窗播放

播放页可以手动进入 Android 系统画中画。打开「返回桌面自动小窗」后，播放中回到桌面就能继续通过小窗观看。

系统小窗权限可以从设置里查看和开启，小窗中的播放控制沿用 Android 系统操作。

### 听音模式

想听新闻、节目或直播声音时，点击「听音」即可进入听音模式。回到桌面或息屏后，声音可以继续播放。

0.4 接入了 Android 标准媒体会话，系统媒体面板可以识别 Tunvix 和当前频道，支持播放、暂停、停止及上一台、下一台控制。后台换台使用当前频道分组，回到应用时频道状态也会同步。

听音页支持 **15、30、45、60 分钟**定时关闭，并显示剩余时间。切到后台、暂停或换台时，定时会继续按原定时间计算。到时间后停止播放；也可以手动关闭定时或退出听音模式，回到正常的视频播放。

## 节目单

应用内置默认 EPG 节目单，也可以在「设置 → EPG 订阅管理」添加自己的订阅，支持 **XML / XML.GZ** 格式。

- 播放页直接查看当前频道的节目安排，切换日期查看其他日期的节目。
- 打开节目单时优先定位到当前节目，并显示播放进度。
- 支持自动匹配频道，也可以手动选择匹配结果、恢复自动匹配。
- 自定义订阅可以设置优先级、编辑、刷新和删除，内置来源用于补充节目数据。
- 可以开启自动更新，也可以手动刷新全部节目单。

## 收藏、最近观看和设置

收藏页集中放常看的频道，收藏后的心形会填满，添加收藏时会有一个简短的动画。最近观看会保留观看记录，点击频道预览、名称或「继续观看」都可以回到播放页。

设置里可以调整：

| 分类 | 可调整内容 |
| --- | --- |
| 播放体验 | 观影柔光、默认播放面板、返回桌面自动小窗、移动网络播放提醒、按键震动反馈 |
| 频道与节目单 | 同名频道合并、频道耗时显示、频道预览检测、EPG 自动更新、直播源和 EPG 订阅管理 |
| 外观 | 跟随系统、浅色、深色 |
| 储存与数据 | 清理截图缓存、清空最近观看 |
| 关于应用 | 版本与系统信息、QQ 群入口 |

## 从源码构建

项目使用 **Kotlin、Jetpack Compose、Android WebView、Media3 / ExoPlayer**。界面资源随应用打包，视频播放、导入、数据保存、小窗和后台听音由 Android 原生模块处理。音频解码包含 FFmpeg 扩展，用于 MP2 等音频格式。

当前工程配置：

| 项目 | 版本 |
| --- | --- |
| 最低 Android 版本 | Android 10 / API 29 |
| Compile SDK / Target SDK | 37 |
| Android SDK Build Tools | 37.0.0 |
| Android Gradle Plugin | 9.1.1 |
| Gradle Wrapper | 9.3.1 |
| Kotlin Compose 插件 | 2.2.10 |
| NDK | 28.2.13676358 |
| CMake | 3.22.1 |

用 Android Studio 打开项目，安装对应的 SDK、NDK 和 CMake，并使用兼容的 JDK。我的本地构建使用 Android Studio 自带的 JBR，macOS 下可以执行：

```sh
git clone https://github.com/QG168/Tunvix.git
cd Tunvix
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:assembleLiveDebug
```

APK 输出位置：

```text
app/build/outputs/apk/live/debug/app-live-debug.apk
```

日常使用和功能开发选择 `live` 变体，应用包名为 `com.tunvix.app`。工程也保留了用于独立界面开发的 `demo` 变体。

主要代码位置：

| 目录 | 内容 |
| --- | --- |
| `app` | 应用入口、界面与原生功能连接、内置台标和品牌资源 |
| `app/src/main/assets/webui` | HTML、CSS、JavaScript 界面 |
| `backend/importer` | 直播源下载与解析 |
| `backend/catalog` | 来源、频道、收藏、观看记录和设置保存 |
| `backend/playback` | 视频播放、系统小窗、后台听音与媒体会话 |
| `backend/audio-decoder` | FFmpeg 音频解码扩展 |
| `core/contract` | 界面与各模块共用的数据及接口 |
| `docs` | 开发方案、功能记录与 UI 调整记录 |
